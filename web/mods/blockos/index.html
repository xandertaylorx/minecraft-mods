BlockScript

A tiny programming language made for Minecraft. Every computer comes with example programs in programs/.

Automatic door

# opens an iron door when someone walks up
loop
  if players(4) > 0
    redstone front on
  else
    redstone front off
  end
  wait 0.25
end

Intruder alarm

# pressure plate on the left side
loop
  if input(left) > 0
    say Intruder alert!
    send 1 intruder at base
    repeat 4
      play bell 18
      wait 0.2
    end
  end
  wait 0.2
end

FAQ

Do programs keep running when I walk away?

Yes, as long as the computer's chunk is loaded. They even pick up again after you reload the world.

Can a program crash my game?

No. Programs run a small number of steps per tick, so even an endless loop can't freeze anything. Use stop to end one.

Does it work in multiplayer?

Yes. Install it on the server and on every player's game. Programs run on the server.

Do I keep my files if I break the computer?

Not in 1.0: breaking the computer wipes it. Keep important programs in a second computer, or just don't break it.
