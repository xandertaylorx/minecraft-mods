Mac FPS Boost

One tiny mod, one job: stop your Mac from drawing Minecraft at 4× the pixels it needs.

Download v1.0.0 How it works

How it works

The problem

On a Retina or 4K screen, macOS makes Minecraft render at the screen's full pixel count. A window that looks like 1920×1080 is really drawing 3840×2160: four times the work, especially with shaders.

The fix

Mac FPS Boost removes the one "high pixel density" setting when the game window is created, so Minecraft draws at normal size and macOS scales it up.

Tested

On an M1 Pro with a 4K screen, pixel density went from 2.0 without the mod to 1.0 with it, which means a quarter of the pixels to draw.

Safe everywhere

On Windows and Linux it does nothing at all, so it's fine to keep in a shared modpack.

The picture is slightly softer than full Retina, the same trade-off as lowering resolution in any game. To switch it off without removing the mod, add -Dmacfpsboost.disable=true to your launcher's Java arguments.
